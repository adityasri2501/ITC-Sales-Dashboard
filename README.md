# ITC Sales Dashboard

A Power BI dashboard project for analyzing ITC hotel sales, bookings, occupancy, and property performance across multiple cities.

## Overview

This repository contains a business intelligence dashboard and supporting dataset files used to evaluate hotel performance trends. The project is centered on an interactive Power BI report (`Minor Visual.pbix`) and a set of CSV datasets located in the `Dataset/` folder.

## Repository Structure

- `Minor Visual.pbix` — Power BI dashboard/report file
- `Dataset/` — raw data used by the dashboard
  - `ITC_Hotels.csv` — core hotel dataset
  - `bookings.csv` — booking records
  - `hotels.csv` — hotel/property master data
  - `occupancy.csv` — occupancy metrics
  - `rooms.csv` — room class definitions

## Data Highlights

The dataset includes hotel property information such as:

- property ID and name
- category (e.g., Luxury, Business)
- city/location
- room classes
- booking and occupancy records for revenue and operational analysis

## How to Use

1. Open the Power BI file (`Minor Visual.pbix`) in Power BI Desktop.
2. Ensure the CSV files in `Dataset/` are available in their original folder structure.
3. Refresh the model if required to load the latest data.
4. Explore the visuals to review sales, occupancy, and property performance trends.

## Notes

- This project is designed for analytical reporting and dashboarding rather than a traditional application codebase.
- The data files are suitable for business intelligence exploration and trend analysis.
